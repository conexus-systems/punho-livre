# web/

O jogo. Abra `index.html` no navegador ou use `npm start` na raiz.

- `index.html`, `style.css`: página, canvas, controles de toque e formulário de rede
- `fonts/`: fonte Bangers (SIL OFL 1.1)
- `src/`: `core/`, `content/`, `engine/`, `ui/`, `audio/`, `net/`. Veja [../docs/ARQUITETURA.md](../docs/ARQUITETURA.md)

Ao criar um arquivo novo em `src/`, liste-o no `index.html` (a ordem importa); `npm run check` avisa se esquecer.
