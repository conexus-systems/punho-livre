# store/

Tudo para a ficha da Play Store.

- `listing-pt-BR.md`: nome, descrições, categoria, preço (grátis, com anúncios) e respostas dos formulários
- `CHECKLIST.md`: passos para publicar e atualizar
- `LEGAL.md`: pontos legais antes de vender
- `politica-de-privacidade.html`: para hospedar (preencha [DATA] e [E-MAIL DE CONTATO])
- `icon-512.png`, `feature-1024x500.png`, `screenshots/`: gerados por `npm run store-assets`
